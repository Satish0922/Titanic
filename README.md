# 🧪 Titanic Dataset - Exploratory Data Analysis (EDA)

This repository contains the Exploratory Data Analysis (EDA) for the Titanic dataset, as part of a Data Analyst Internship Task.

---

## 📁 Files Included

- `train.csv` — Training dataset
- `test.csv` — Test dataset
- `gender_submission.csv` — Sample submission data
- `Titanic_EDA.ipynb` — Jupyter Notebook with all EDA steps
- `Titanic_EDA_Report.pdf` — PDF report exported from the notebook

---

## 🔍 Objective

The main goal of this task is to extract useful insights from the Titanic dataset using statistical and visual exploration methods.

---

## 🧰 Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 EDA Highlights

- **Data Cleaning**: Checked for missing values and handled them using median/mode.
- **Univariate Analysis**: Analyzed distributions of features like Age, Fare, Sex, Pclass.
- **Bivariate Analysis**: Explored relationships between survival and other variables.
- **Visualizations**:
  - Count plots, histograms, boxplots
  - Correlation heatmap
  - Pairplot for multivariate overview
- **Insights**:
  - Females had a higher survival rate than males.
  - Passengers in higher classes were more likely to survive.
  - Younger passengers had a better survival rate on average.

---

## 📌 How to Run

1. Clone this repository
2. Open `Titanic_EDA.ipynb` using Jupyter Notebook
3. Run the notebook step by step
